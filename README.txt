齋藤村 表玄関ページ

このフォルダの4ファイルを、そのまま静的Webホスティングへ配置してください。

- index.html
- apple-touch-icon.png
- icon-512.png
- favicon.png

GitHub Pagesを使う場合は、リポジトリ直下へ4ファイルを置くだけで使えます。
公開された入口URLを村民へ共有してください。

ホーム画面に追加するときは、必ずこの「表玄関ページ」のURLをSafariで開いてから
「共有」→「ホーム画面に追加」を実行します。

「齋藤村へ入村する」を押すと、現在のGoogle Apps Script版ポータルへ移動します。
